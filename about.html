关于工具箱

免费、无广告、纯前端、离线可用的在线实用工具箱

关于我们

工具箱是一个完全免费、开源、无广告的在线实用工具集合站点。我们的使命是提供高质量、即开即用的查询计算工具，让每个人都能随时随地获得所需的计算和转换结果，无需注册、无需下载、无需担心隐私泄露。

核心理念

  • 完全免费 - 所有工具永久免费使用，无任何隐形收费
  • 无广告干扰 - 纯净界面，专注工具本身
  • 纯前端架构 - 所有计算在浏览器本地完成，数据不上传服务器
  • 离线可用 - 支持 PWA 安装，断网也能用
  • 极速加载 - 静态资源 CDN 分发，毫秒级打开
  • 全平台适配 - PC、手机、平板完美自适应

技术栈

HTML5 + Tailwind CSS v3 + 原生 JavaScript (ES6+)，无框架依赖，代码轻量、可审计、易维护。

隐私政策

最后更新：2025年1月

数据收集

我们不收集任何个人身份信息。 工具箱采用纯前端架构，所有计算、转换、生成操作均在您的浏览器本地完成，数据不会上传到任何服务器。

本地存储

我们仅在您的浏览器本地存储以下非敏感偏好设置：

  • 主题偏好（浅色/深色/跟随系统）
  • 收藏的工具列表
  • 最近使用的工具历史记录（最多20条）

这些数据仅存储在您的浏览器 localStorage 中，我们无法访问、无法同步、不会上传。

第三方服务

工具箱不集成任何第三方分析、广告、追踪服务（如 Google Analytics、百度统计等）。IP 查询功能使用免费公开 API（ipify.org、ip-api.com），仅在您主动点击查询时发起请求，我们不记录查询日志。

您的权利

您可以随时清除浏览器缓存和 localStorage 来删除所有本地数据。我们不保留任何服务端日志。
